     포함되지 않습니다. 호스트명을 아는 사람은 누구나 이 앱으로 토큰을 씁니다.

  콘솔의 **애플리케이션 열기 링크**에 위 URL을 직접 넣어야 [열기] 버튼이 생깁니다.
  Runway는 이 차트의 hostnames를 읽지 않습니다 — 호스트명을 두 군데에 각각 입력하는
  구조입니다.

  외부 노출이 꺼져 있습니다. 포트 포워드로 접근하세요:

    kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "llm-tutorial.fullname" . }} 8080:{{ .Values.service.port }}

확인:

  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "llm-tutorial.fullname" . }}
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "llm-tutorial.fullname" . }} --tail=50

  로그에서 볼 것 — "MCP 서버 기동: N개 툴" 과 "임베딩: ..." 두 줄.
  앞의 것이 없으면 MCP 자식 프로세스가 못 떴고(문서 기능 없음), 뒤의 것이 없으면
  아직 아무도 문서를 올리지 않은 것입니다.
