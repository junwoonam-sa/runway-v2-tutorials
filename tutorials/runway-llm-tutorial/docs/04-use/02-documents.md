# 4-2. 문서 올리기

내 문서를 벡터 DB에 넣습니다.

걸리는 시간 10분.

---

## 올리기

화면 오른쪽 위 **문서** 버튼 → **파일 올리기**.

마크다운(`.md`)이나 텍스트(`.txt`) 파일을 고릅니다. 여러 개를 한 번에 골라도 됩니다.

시험해 볼 파일이 없다면, 이 저장소의 `samples/` 폴더에 두 개가 들어 있습니다.
없으면 아래 내용을 메모장에 붙여 넣고 `휴가규정.txt` 로 저장해서 올려 보세요.

```
# 휴가 규정

연차는 15일입니다.
반차는 하루 두 번까지 쓸 수 있습니다.
연차 신청은 최소 3일 전에 해야 합니다.

# 재택근무

주 2회까지 가능합니다.
전날 오후 6시까지 신청합니다.
```

---

## 올리면 이렇게 나옵니다

```
✓ 휴가규정.txt — '휴가규정.txt' 색인 완료: 2 chunks
```

**chunks(조각)** 는 문서를 쪼갠 수입니다. 검색은 문서 단위가 아니라 이 조각 단위로
이루어집니다. 그래서 긴 문서에서도 필요한 대목만 골라낼 수 있습니다.

오른쪽 목록에도 나타납니다.

```
- 휴가규정.txt (2 chunks)
```

---

## 벡터 DB에 실제로 들어갔는지 확인 (선택)

챗봇 화면을 믿지 않고 벡터 DB에 직접 물어볼 수도 있습니다.
Code Server 터미널에서:

```bash
curl -s http://qdrant.<프로젝트 ID>.svc.cluster.local:6333/collections
```

이제 이름이 하나 생겼습니다.

```json
{"result":{"collections":[{"name":"tutorial-docs"}]},"status":"ok"}
```

---

## 알아 둘 것

**같은 이름의 파일을 다시 올리면** 예전 것을 지우고 새로 넣습니다.
문서를 고쳤을 때 그냥 다시 올리면 됩니다.

**지원하는 형식은 텍스트 계열입니다** — `.md`, `.txt`, `.rst`.
PDF나 Word 파일은 지금은 안 됩니다. 내용을 복사해서 텍스트로 저장하면 됩니다.

**한 파일에 5 MB 제한**이 있습니다.

---

## 여기까지 되면 성공

- [ ] 파일을 올렸고 `색인 완료: N chunks` 메시지가 나왔다
- [ ] 오른쪽 문서 목록에 파일 이름이 보인다
- [ ] 상태 화면의 벡터 DB 항목에 조각 수가 0보다 크게 나온다

---

## 막혔다면

| 이런 화면이 나오면 | 이렇게 하세요 |
|---|---|
| `지원하지 않는 확장자` | `.md` 나 `.txt` 로 저장해서 올리세요 |
| `UTF-8 텍스트가 아닙니다` | 메모장에서 "UTF-8"로 저장한 뒤 다시 올리세요 |
| `MCP 서버에 연결되어 있지 않습니다` | 3-2의 도구 서버 항목을 확인하세요 |
| 올렸는데 `0 chunks` | 파일이 비어 있거나 공백뿐입니다 |
