# 4-1. 대화해 보기

먼저 평범하게 말을 걸어 봅니다.

걸리는 시간 5분.

---

## 첫 메시지

화면 아래 입력창에 아무거나 써 보세요.

```
안녕? 너는 무엇을 할 수 있어?
```

글자가 **하나씩 흘러나오면** 정상입니다. 답이 다 만들어질 때까지 기다렸다가
한꺼번에 나오는 것이 아니라, 만들어지는 대로 보내 줍니다.

여기까지는 평범한 챗봇입니다. 문서 기능은 4-2에서 붙입니다.

---

## 알아 둘 것

**대화 기억은 브라우저에 있습니다.** 화면을 새로고침하면 대화가 초기화됩니다.
서버는 대화를 저장하지 않습니다.

**답변이 마음에 안 들 수 있습니다.** 이 튜토리얼이 쓰는 것은 플랫폼에 설치된 AI
모델이고, 크기가 작을 수 있습니다. 지금 확인하는 것은 **답변 품질이 아니라 연결**
입니다.

**Shift+Enter 로 줄바꿈**, 그냥 Enter는 전송입니다.

---

## 답이 안 나온다면

| 이런 화면이 나오면 | 이렇게 하세요 |
|---|---|
| 입력창이 회색이고 안 눌림 | 상태 배지가 🔴 입니다. 3-2로 돌아가 항목을 확인하세요 |
| 빨간 글씨로 오류가 뜸 | 오류 내용에 원인이 적혀 있습니다 |
| 한참 기다려도 아무 반응 없음 | 모델이 느린 경우입니다. 1분 정도 기다려 보세요 |
| 답이 한꺼번에 나옴 | 동작에는 문제없습니다 |

---

## 여기까지 되면 성공

- [ ] 메시지를 보내면 답이 돌아온다
- [ ] 글자가 하나씩 흘러나온다
