# 4-3. 에이전트 동작 확인

챗봇이 **스스로 판단해서** 문서를 뒤지는 것을 봅니다.

걸리는 시간 10분. 이 튜토리얼에서 가장 볼 만한 부분입니다.

---

## 물어보기

4-2에서 올린 문서 안에 있는 내용을 물어보세요.

```
연차가 며칠이라고 되어 있어?
```

답이 나오기 전에 **접힌 줄 두 개**가 먼저 뜹니다.

```
▸ 도구 호출: search_documents
▸ 도구 결과: search_documents
```

그다음 답이 나옵니다.

```
문서에 따르면 연차는 15일입니다. 반차는 하루 두 번까지 쓸 수 있고,
연차 신청은 최소 3일 전에 해야 합니다.
```

---

## 방금 무슨 일이 일어났나

```
  질문
    │
    ▼
  AI가 판단: "이건 저장된 문서를 봐야겠다"      ← 우리가 시킨 게 아닙니다
    │
    ▼
  도구 호출: search_documents("연차")
    │
    ▼
  벡터 DB에서 관련 문단을 찾아옴
    │
    ▼
  그 문단을 근거로 답변
```

**우리는 "검색해"라고 시키지 않았습니다.** 그냥 물어봤을 뿐입니다.
AI가 도구 목록을 보고 스스로 골라 쓴 것입니다.

이것이 **에이전트**입니다. 그냥 챗봇은 아는 것만 답하고, 에이전트는 필요하면
도구를 써서 알아본 뒤 답합니다.

접힌 줄을 **클릭해서 펼치면** 어떤 검색어를 썼고 무엇을 찾았는지 볼 수 있습니다.

---

## 도구를 안 쓰는 질문도 있습니다

```
1 더하기 1은?
```

이 질문에는 도구 호출 줄이 **나오지 않습니다.** 문서를 볼 이유가 없다고 판단한
것입니다.

```
안녕하세요
```

이것도 마찬가지입니다.

**이 구분을 스스로 하는 것**이 핵심입니다. 매번 검색하면 느리고, 안 하면 문서를
못 씁니다.

---

## 도구는 다섯 개인데 두 개만 보입니다

상태 화면(3-2)에 "도구 5개"라고 나왔는데, AI가 쓰는 것은 두 개뿐입니다.

| 도구 | AI에게 보이나 | 왜 |
|---|---|---|
| `search_documents` | ✅ | 문서 찾기 |
| `list_documents` | ✅ | 무슨 문서가 있는지 |
| `index_document` | ❌ | 문서를 **넣는** 동작 |
| `delete_document` | ❌ | 문서를 **지우는** 동작 |
| `collection_info` | ✅ | 벡터 DB 상태 보기 |

**쓰기 동작은 AI에게 보여 주지 않습니다.** 대화 중에 AI가 스스로 문서를 지울 이유는
없으니까요. 문서를 넣고 지우는 것은 사람이 화면에서 합니다.

---

## 답이 시원찮을 때

| 이런 답이 나오면 | 왜 그런가 | 해 볼 것 |
|---|---|---|
| "문서에 없습니다" 인데 분명히 있음 | 검색어와 문서의 표현이 다름 | 문서에 실제로 쓰인 단어로 물어보세요 |
| 엉뚱한 내용을 가져옴 | 질문이 짧거나 일반적임 | 고유명사나 구체적인 용어를 넣어 보세요 |
| 도구를 아예 안 부름 | 문서가 필요한 질문으로 안 보임 | "문서에서", "우리 자료에" 같은 말을 붙여 보세요 |
| 예전 내용으로 답함 | 문서를 고쳤는데 다시 안 올림 | 같은 파일명으로 다시 올리세요 |

---

## 상단 배지 옆의 표시

| 표시 | 뜻 |
|---|---|
| **도구 호출** | 정상입니다. AI가 스스로 판단해서 검색합니다 |
| **검색 주입(폴백)** | AI 모델이 도구 기능을 지원하지 않아, 매번 먼저 검색하고 답합니다. 조금 투박하지만 동작합니다 |
| **도구 없음** | 문서 기능이 꺼져 있습니다. 3-2를 보세요 |

**"검색 주입(폴백)"이 떠도 고장이 아닙니다.** 작은 AI 모델은 도구 기능을 지원하지
않는 경우가 많고, 그때 챗봇이 알아서 다른 방식으로 갈아탄 것입니다.

---

## 여기까지 되면 성공

- [ ] 문서 내용을 물으면 `도구 호출` 줄이 나온다
- [ ] 답에 문서의 내용이 반영되어 있다
- [ ] "1 더하기 1은?" 에는 도구 호출 줄이 안 나온다

**여기까지 오면 챗봇은 완성입니다.** 남은 5단계는 팀에 공개하는 방법입니다.
