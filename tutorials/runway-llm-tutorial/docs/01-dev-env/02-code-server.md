# 1-2. Code Server 배포

브라우저에서 열리는 작업 화면을 만듭니다.

걸리는 시간 15분.

---

## 왜 필요한가

Code Server는 브라우저에서 열리는 작업 화면입니다. 이 튜토리얼에서는 딱 두 가지에
씁니다.

- **OpenBao의 키가 실제로 전달되는지 확인** (다음 페이지)
- **문서 창고에 연결되는지 확인** (2-2)

챗봇을 만드는 데 반드시 필요한 것은 아니지만, 여기서 미리 확인해 두면 나중에 챗봇이
안 될 때 **어디가 문제인지 이미 알고 시작**하게 됩니다.

---

## 만들기

왼쪽 메뉴 **애플리케이션(Applications)** → **생성(Create)** → 목록에서
**Code Server** 카드를 고릅니다.

### 채울 칸

| 그룹 | 칸 | 넣을 값 |
|---|---|---|
| 기본 | 이름 | `Code Server` |
| 기본 | **ID** | `code-server` |
| 네트워크 | 외부 접근 | **켬** |
| 네트워크 | 호스트명 | `code-<프로젝트 ID>.<도메인>` |
| 시크릿 | OpenBao 엔진 | `tutorial` |
| 시크릿 | OpenBao 시크릿 이름 | `llmchat` |

나머지는 기본값 그대로 둡니다.

### YAML로 한 번에 넣기

**YAML** 탭을 누르면 차트의 값이 전부 적힌 긴 파일이 보입니다. 그 안에서 칸을 찾아
고쳐도 되지만, **내용을 전부 지우고 아래를 붙여 넣는 편이 확실합니다.**

```yaml
runway:
  httpRoute:
    enabled: true
    hostname: "code-<프로젝트 ID>.<도메인>"   # 전부 소문자
    targetPort: 8080

code-server:
  runway:
    openbaoSecretEngine: "tutorial"    # 0-1 템플릿 ②의 '시크릿 엔진'
    openbaoSecretName: "llmchat"       # 0-1 템플릿 ②의 '시크릿 이름'
```

`<프로젝트 ID>` 와 `<도메인>` 만 내 값으로 바꿉니다. 지운 값들은 사라지는 것이
아니라 **차트 기본값으로 돌아갑니다** — 저장 공간 10Gi, 자원 요청, 이미지 주소가
전부 그대로입니다.

> ⚠ **지우지 않고 위에 덧붙이면 안 됩니다.** 같은 키가 두 번 생기고, YAML은
> **뒤에 나온 것이 이깁니다.** 원래 파일 아래쪽에도 `openbaoSecretEngine: ""` 이
> 있어서, 위에 붙여 넣으면 빈 값이 이기고 시크릿 주입이 조용히 꺼집니다.
> 오류도 안 나고 `/vault/secrets` 디렉터리 자체가 생기지 않습니다.

> **`runway:` 가 파일에 두 번 나옵니다.** 맨 위의 것은 주소(HTTPRoute)를 다루고,
> `code-server:` 안에 있는 것이 시크릿을 다룹니다. 시크릿 두 줄은 반드시
> **`code-server:` 안쪽**이어야 합니다.


호스트명 예시 — 프로젝트가 `my-project`, 도메인이 `mycompany.com` 이라면:

```
code-my-project.mycompany.com
```

> ⚠ **호스트명은 전부 소문자여야 합니다.** 대문자가 하나라도 있으면 배포가
> 실패하고, 오류 메시지가 알아보기 어려운 형태로 나옵니다.

> ⚠ **시크릿 칸 두 개는 반드시 함께 채우세요.** 하나만 채우면 시크릿 전달 기능이
> 그냥 꺼집니다 — 오류도 안 나고 조용히 안 됩니다.

### 애플리케이션 열기 링크

같은 화면 아래쪽에 **애플리케이션 열기 링크** 라는 부분이 있습니다.
여기에 방금 정한 주소를 **한 번 더** 넣습니다.

```
이름 : Code Server
URL  : https://code-my-project.mycompany.com
```

> 위에서 호스트명을 적었는데 왜 또 적나 싶겠지만, 두 칸은 서로 연결되어 있지
> 않습니다. 여기를 비우면 나중에 **열기 버튼이 생기지 않습니다.**

---

## 생성하고 배포하기

**생성**을 누릅니다. 목록에 나타나지만 아직 아무것도 실행되지 않았습니다.

목록에서 방금 만든 것을 클릭해 상세 화면으로 들어간 다음, **배포(Deploy)** 를
누릅니다.

상태가 `Healthy` 가 될 때까지 1~2분 기다립니다. 첫 실행은 조금 느립니다 —
작업 화면에 필요한 것들을 처음 한 번 준비하기 때문입니다.

---

## 열어 보기

상세 화면에서 **열기(Open)** 를 누르면 새 탭에 작업 화면이 뜹니다.

처음 열면 화면이 비어 있는 것이 정상입니다. 다음 페이지에서 여기 터미널을 씁니다.

---

## 여기까지 되면 성공

- [ ] Code Server가 `Healthy` 다
- [ ] 열기 버튼이 보이고, 눌렀을 때 작업 화면이 뜬다

---

## 막혔다면

| 이런 화면이 나오면 | 원인 | 이렇게 하세요 |
|---|---|---|
| 생성했는데 아무것도 실행 안 됨 | 배포 버튼 미클릭 | 상세 화면 → **배포** |
| 열기 버튼이 없음 | 열기 링크를 비웠음 | 링크를 넣고 다시 배포 |
| 배포가 실패하고 긴 오류 | 호스트명에 대문자 | 소문자로 고치고 다시 배포 |
| 배포가 실패하고 길이 오류 | ID가 너무 김 | 짧은 ID로 다시 만드세요 (ID는 수정 불가) |
| `exceeded quota` | 프로젝트 자원 부족 | 안 쓰는 애플리케이션을 정리하거나 관리자에게 증설 요청 |
| 화면은 열리는데 계속 로딩 | 첫 실행 준비 중 | 30~40초 기다려 보세요 |
