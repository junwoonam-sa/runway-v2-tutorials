# 1-1. PVC 생성

챗봇이 쓸 저장 공간을 만듭니다.

걸리는 시간 5분.

---

## PVC가 무엇인가

**PVC(Persistent Volume Claim)** 는 "이만큼의 디스크를 주세요"라는 요청입니다.
Runway 화면에서는 **볼륨** 또는 **스토리지**라고 부릅니다 — 같은 것입니다.

여기 담기는 것이 **애플리케이션이 재시작해도 남습니다.** 반대로 볼륨 없이 돌면
재시작할 때마다 초기 상태로 돌아갑니다.

---

## 만들기

왼쪽 메뉴 **스토리지(Storage)** → 우측 상단 **생성(Create)**.

칸이 네 개뿐입니다.

| 칸 | 넣을 값 |
|---|---|
| 볼륨 ID | `llm-tutorial-data` |
| 스토리지 클래스 | **그대로 두세요** (미리 선택되어 있습니다) |
| 접근 모드 | **ReadWriteOnce** (기본값) |
| 크기 | `5` |

**생성**을 누릅니다. 목록에 나타나고 잠시 뒤 상태가 `Bound` 가 되면 준비된 것입니다.

> 볼륨은 배포 버튼이 따로 없습니다. 만들면 바로 준비됩니다.

---

## 알아 둘 것

**이름은 나중에 바꿀 수 없습니다.** 크기는 나중에 늘릴 수만 있고, 줄일 수는 없습니다.
5 GiB면 이 튜토리얼에는 넉넉합니다.

**이름 규칙이 있습니다.** 소문자·숫자·하이픈만 쓸 수 있고, 시작과 끝은 소문자나
숫자여야 합니다. 위의 `llm-tutorial-data` 는 규칙에 맞습니다.

**크기 칸 옆의 숫자**는 프로젝트에 남은 용량입니다. 그것보다 크게 요청하면 만들어지지
않습니다.

---

## 여기까지 되면 성공

- [ ] 스토리지 목록에 `llm-tutorial-data` 가 있다
- [ ] 상태가 `Bound` 다

---

## 막혔다면

| 이런 화면이 나오면 | 원인 | 이렇게 하세요 |
|---|---|---|
| 상태가 `Pending` 에서 안 넘어감 | 고른 스토리지 클래스가 이 요청을 처리하지 못함 | 지우고 다른 클래스로 다시 만들어 보세요 |
| `이미 존재합니다` | 같은 이름이 이미 있음 | 다른 이름을 쓰거나 기존 것을 씁니다 |
| 크기를 넣었는데 거부됨 | 프로젝트 남은 용량 초과 | 더 작게 요청하거나 안 쓰는 볼륨을 정리하세요 |
| 접근 모드에서 오류 | `ceph-block` 클래스는 여러 곳에서 동시에 쓸 수 없음 | `ReadWriteOnce` 로 두세요 |
