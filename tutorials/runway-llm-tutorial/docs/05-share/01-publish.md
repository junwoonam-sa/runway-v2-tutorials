# 5-1. 팀에 공개하기

지금은 나만 볼 수 있습니다. 팀원들도 쓰게 하는 방법입니다.

걸리는 시간 10분.

---

## 먼저 읽어야 할 것

> ⚠ **애플리케이션 주소 앞에는 로그인이 붙지 않습니다.**
>
> Runway 콘솔에는 로그인이 있지만, 우리가 만든 애플리케이션 주소는 거기 포함되지
> 않습니다. **주소를 아는 사람은 누구나** 이 챗봇을 쓸 수 있습니다. 그 말은:
>
> - 프로젝트의 AI 사용량을 아무나 쓸 수 있고
> - 올려 둔 문서를 아무나 검색할 수 있다는 뜻입니다.
>
> 사내 문서를 올렸다면 가볍게 넘길 일이 아닙니다.

막는 방법이 두 가지 있고, **둘을 같이 쓸 수 있습니다.**

---

## 방법 1 — 열지 않기

지금처럼 두고, 쓸 때만 잠깐 연결하는 방법입니다(3-2의 `port-forward`).
혼자 쓰거나 가끔 쓴다면 이게 제일 안전합니다.

이 경우 5단계는 여기서 끝입니다.

---

## 방법 2 — 비밀번호 걸고 열기

여러 사람이 써야 한다면 비밀번호를 먼저 걸고 주소를 엽니다.

### 1) OpenBao에 비밀번호 추가

**0-2에서 `ACCESS_PASSWORD` 를 이미 넣었다면 이 단계는 건너뛰세요.**
1-3에서 확인한 파일에 두 줄이 나왔다면 이미 되어 있는 것입니다.

아직 안 넣었다면, OpenBao로 갑니다 (0-2와 같은 경로, Namespace 칸에 프로젝트 ID).

1. `tutorial` 엔진 → `llmchat` 시크릿 → **Create new version**
2. **JSON** 토글을 켜고, 아래처럼 **두 개가 다 들어가게** 만듭니다

```json
{
  "LLM_API_KEY": "sk-기존값-그대로",
  "ACCESS_PASSWORD": "아무도-못-맞출-긴-문자열"
}
```

3. **Save**

> ⚠ **기존 `LLM_API_KEY` 를 빠뜨리지 마세요.**
> 새 버전은 이전 내용을 물려받지 않고 **통째로 대체**합니다. `ACCESS_PASSWORD` 만
> 남기면 챗봇이 키를 잃고 멈춥니다.

### 2) 주소 열기

애플리케이션 → `llm-chat` → 설정 수정 → **YAML** 탭에서:

```yaml
runway:
  access:
    passwordRequired: true

  httpRoute:
    enabled: true
    hostnames:
      - "llm-chat-my-project.mycompany.com"    # 전부 소문자
```

> ⚠ **호스트명은 전부 소문자여야 합니다.** 대문자가 하나라도 있으면 배포가
> 거부됩니다. 다행히 배포 전에 이유를 말해 주고 거부하므로, 클러스터에는 아무것도
> 만들어지지 않습니다.

### 3) 열기 링크 확인

**애플리케이션 열기 링크** 에 같은 주소가 들어 있는지 확인합니다.
3-1에서 넣어 두었다면 그대로 두면 됩니다.

```
이름 : 챗봇
URL  : https://llm-chat-my-project.mycompany.com
```

> 호스트명을 두 군데에 각각 넣는 구조입니다. 한쪽만 고치면 열기 버튼이 엉뚱한
> 곳으로 갑니다.

### 4) 다시 배포

상세 화면에서 **배포**를 다시 누릅니다. `Healthy` 가 되면 **열기** 버튼으로
접속할 수 있습니다.

이제 처음 열 때 비밀번호를 묻습니다.

---

## 비밀번호에 대해

공용 비밀번호는 **신원이 아닙니다.** 지나가던 사람의 사용을 막을 뿐, 누가 무엇을
물었는지는 알려 주지 않습니다. 그래도 없는 것보다 훨씬 낫습니다.

팀원에게 주소와 비밀번호를 함께 전달하세요.

---

## 다 끝났습니다

만든 것을 정리하면 이렇습니다.

| 만든 것 | 하는 일 |
|---|---|
| 시크릿 이름 (`tutorial/llmchat`) | 키를 설정 밖에 보관 |
| 볼륨 (`llm-tutorial-data`) | 챗봇의 저장 공간 |
| Code Server | 확인용 작업 화면 |
| Qdrant | 벡터 DB |
| 챗봇 (`llm-chat`) | 대화 + 문서 검색 |

챗봇 안에는 **에이전트**와 **MCP 도구 서버**가 들어 있습니다. 질문을 보고 검색이
필요한지 판단하는 것이 에이전트, 실제로 벡터 DB를 뒤지는 도구를 제공하는 것이 MCP
서버입니다. 따로 설치하지 않았는데도 처음부터 돌고 있었습니다.
