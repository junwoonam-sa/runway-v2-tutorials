# 2-1. Qdrant 배포

챗봇이 문서를 넣어 둘 창고를 만듭니다.

걸리는 시간 10분.

---

## 이게 왜 필요한가

챗봇에게 회사 문서를 읽히려면, 문서를 어딘가에 넣어 두고 **질문에 맞는 대목만
빠르게 찾아낼** 수 있어야 합니다.

문서 전체를 통째로 AI에게 보내면 안 되는 이유가 두 가지입니다. 한 번에 읽을 수 있는
양에 한계가 있고, 관계없는 내용까지 섞이면 답이 부정확해집니다.

그래서 **Qdrant** 라는 창고를 씁니다. 문서를 문단 단위로 쪼개 넣어 두었다가, 질문이
들어오면 **뜻이 가까운 문단**만 골라 줍니다.

```
   문서 올리기 ──▶ 문단으로 쪼갬 ──▶ Qdrant 창고에 저장
                                          │
   "휴가 며칠이야?" ──────────────────────┘──▶ 관련 문단 몇 개 ──▶ AI가 그걸 보고 답변
```

> **챗봇보다 창고를 먼저 만듭니다.** 챗봇을 만들 때 창고 주소를 적어 넣어야 하기
> 때문입니다. 순서를 바꾸면 챗봇을 두 번 배포하게 됩니다.

---

## 만들기

**애플리케이션(Applications)** → **생성(Create)** → 목록에서 **Qdrant** 카드.

### 채울 칸

| 그룹 | 칸 | 넣을 값 |
|---|---|---|
| 기본 | 이름 | `Qdrant` |
| 기본 | **ID** | `qdrant` ← 메모에 적어 두세요 |
| 네트워크 | **외부 접근** | **끔** ← 아래 설명을 꼭 읽으세요 |
| 스토리지 | 볼륨 크기 | `1` 이상 |

나머지는 전부 기본값 그대로 둡니다.

> ⚠ **외부 접근을 켜지 마세요.**
>
> Qdrant에는 비밀번호를 거는 기능이 없습니다. 그리고 Runway는 애플리케이션 주소
> 앞에 로그인을 붙여 주지 않습니다. 두 가지가 겹치면 — **주소를 아는 사람은 누구나
> 올려 둔 문서를 전부 읽고 지울 수 있습니다.**
>
> 우리 챗봇은 같은 프로젝트 안에서 부르기 때문에 외부 접근이 필요 없습니다.
> 꺼 두는 것이 맞습니다.

### 폼 대신 YAML로 넣기

**YAML** 탭이 있으면 아래를 그대로 붙여 넣어도 됩니다.

```yaml
runway:
  httpRoute:
    enabled: false        # 외부 접근 끔 — 위 주의 참고

qdrant:
  persistence:
    enabled: true
    size: 1Gi             # 나중에 늘릴 수만 있습니다
```

바꿀 값이 없습니다. 그대로 붙여 넣으면 됩니다 — 이 튜토리얼에서 Qdrant는
프로젝트 안에서만 쓰이고, 주소는 애플리케이션 **ID**(`qdrant`)로 결정되기 때문입니다.

**생성** → 상세 화면에서 **배포(Deploy)** → 상태가 `Healthy` 가 될 때까지 기다립니다.

---

## 창고 주소 만들어 두기

3단계에서 이 주소를 챗봇 설정에 넣습니다. 지금 만들어 메모에 추가하세요.

빈칸 두 개를 채우면 됩니다.

```
http://<Qdrant의 ID>.<프로젝트 ID>.svc.cluster.local:6333
         └────┬────┘  └─────┬─────┘
        방금 만든 ID    0-1에서 적어 둔 것
```

예시 — Qdrant ID가 `qdrant`, 프로젝트가 `my-project` 라면:

```
http://qdrant.my-project.svc.cluster.local:6333
```

0-1 템플릿 ②의 `창고 주소` 줄에서 `<your-project-id>` 를 내 값으로 바꾸면
이렇게 됩니다.

```
창고 주소        : http://qdrant.my-project.svc.cluster.local:6333
```

Qdrant 앱 ID를 `qdrant` 가 아닌 다른 이름으로 만들었다면, 주소 맨 앞도 그 이름으로
바꾸고 템플릿의 `Qdrant 앱 ID` 줄도 함께 고치세요.

> 이 주소는 **프로젝트 안에서만** 통합니다. 브라우저 주소창에 넣으면 안 열립니다 —
> 그게 정상입니다. 외부에 노출하지 않았으니까요.

---

## 여기까지 되면 성공

- [ ] 애플리케이션 목록에 Qdrant가 `Healthy` 로 있다
- [ ] 외부 접근이 꺼져 있다
- [ ] 창고 주소를 메모에 적었다

## 막혔다면

| 이런 화면이 나오면 | 이렇게 하세요 |
|---|---|

| 상태가 계속 `Progressing` | 1~2분 기다려 보세요. 그 뒤에도 그대로면 자원 부족일 수 있습니다 |
| `exceeded quota` | 안 쓰는 애플리케이션을 정리하세요 |
