# 0-1. 환경 정보 및 인증 키 발급

챗봇이 AI에게 말을 걸 때 쓸 API 키를 만듭니다.

걸리는 시간 10분 · 전부 화면에서 클릭하는 작업입니다.

---

## 환경 정보 적어 두기

Runway 콘솔에 로그인합니다. 주소창이 이렇게 생겼습니다.

```
https://runway.mycompany.com
        └──────┬──────┘
          이 뒤가 "도메인"
```

이 두 값을 확인해 두세요. 아래 [값 채우기 템플릿](#값-채우기-템플릿)에 넣습니다.

| 값 | 어디서 | 예 |
|---|---|---|
| Runway 도메인 | 주소창의 `runway.` 뒤 | `mycompany.com` |
| 프로젝트 ID | 프로젝트 목록에서 보이는 이름 | `my-project` |

> **프로젝트 ID를 정확히 적으세요.** 2단계에서 Qdrant 주소를 만들 때, 3단계에서
> 챗봇 설정을 채울 때 이 이름이 그대로 들어갑니다. 대소문자와 하이픈까지 그대로요.

---

## 키는 세 종류입니다

Runway에는 키가 세 개 있고, **생김새도 쓰임새도 다릅니다.** 우리에게 필요한 것은
가운데 하나뿐입니다.

| 탭 이름 | 생김새 | 무엇에 쓰나 |
|---|---|---|
| API 키 | `eyJ...` | 다른 기능들 — **이번에는 안 씁니다** |
| **LLM API 키** | `sk-...` | **AI에게 말을 거는 데 씁니다 ← 이것** |
| S3 키 | 두 줄짜리 | 파일 저장소 — 이번에는 안 씁니다 |

세 탭이 **같은 화면에 나란히** 있어서 헷갈리기 쉽습니다. 가운데를 고르세요.

---

## 발급하기

1. 콘솔 우측 위 **내 계정 아이콘** 클릭
2. **설정(Settings)**
3. **액세스 키(Access keys)** 탭
4. 그 안에서 다시 **LLM API 키(LLM API Keys)** 탭 — 가운데입니다
5. **생성(Create)** 버튼

값이 창에 한 번 뜹니다. `sk-` 로 시작하는 긴 문자열입니다.

> ⚠ **이 값은 딱 한 번만 보입니다.**
> 창을 닫으면 다시 볼 수 없습니다. **지금 복사해서 메모장에 붙여 넣으세요.**
> 놓쳤다면 지우고 새로 만들면 됩니다 — 어렵지 않습니다.

---

## 잘 만들어졌는지 확인

받은 값이 `sk-` 로 시작하는지 보세요.

| 받은 값 | 뜻 |
|---|---|
| `sk-` 로 시작 | ✅ 맞습니다 |
| `eyJ` 로 시작 | ❌ 옆 탭(`API 키`)에서 만들었습니다. 다시 만드세요 |

`eyJ` 로 시작하는 값을 넣으면 챗봇이 시작할 때 **"키의 모양이 다릅니다"** 라고
알려 줍니다. 하지만 지금 확인하는 편이 빠릅니다.

## 값 채우기 템플릿

아래 두 블록을 메모장에 복사해, 각 항목을 확인하면서 채워 두세요.
이후 단계에서 그대로 씁니다.

### ① OpenBao에 붙여넣을 JSON

이 JSON은 다음 단계(0-2)에서 **OpenBao UI에 그대로 붙여넣습니다.**

```json
{
  "LLM_API_KEY": "<발급받은-LLM-API-키>",
  "ACCESS_PASSWORD": "<아무도-못-맞출-긴-문자열>"
}
```

- `LLM_API_KEY` 는 방금 발급한 값입니다. `sk-` 로 시작합니다.
- `ACCESS_PASSWORD` 는 챗봇에 접속할 때 물어볼 비밀번호입니다. **지금 정해 두세요** —
  3단계에서 챗봇을 열 때 필요합니다. 짐작할 수 없는 긴 문자열이면 됩니다.
  애플리케이션 주소 앞에는 플랫폼 로그인이 붙지 않아서, 이것이 유일한 문입니다.

**OpenBao에는 이 둘만 들어갑니다.** 아래 ②의 값들은 비밀이 아니라서 3단계의 차트
값에 적습니다 — [왜 그렇게 나뉘는지](02-openbao.md)는 다음 단계에 설명이 있습니다.

### ② 차트 값에 쓸 메모

3단계에서 이 값들을 폼과 YAML에 입력합니다.

```
Runway 도메인    : <your-runway-domain>
프로젝트 ID      : <your-project-id>

시크릿 엔진      : tutorial
시크릿 이름      : llmchat
PVC 이름         : llm-tutorial-data
Qdrant 앱 ID     : qdrant
Qdrant 주소      : http://qdrant.<your-project-id>.svc.cluster.local:6333

차트 리포지토리  : https://<your-github-account>.github.io/runway-llm-tutorial
```

- 위의 두 줄(`<your-...>`)만 **지금** 채우면 됩니다. 주소창과 프로젝트 목록에서
  확인한 값입니다.
- 가운데 다섯 줄은 **기본값을 그대로 써도 됩니다.** 0-2부터 2-1까지 그 이름으로
  만들게 됩니다. 다른 이름을 쓰고 싶으면 여기서 바꿔 두고 계속 그 이름을 쓰세요.
- `Qdrant 주소` 의 `<your-project-id>` 는 위에서 채운 값과 같습니다.
  2-1에서 다시 확인합니다.
- `차트 리포지토리` 는 이 튜토리얼 저장소가 올라간 GitHub 계정 이름입니다.
  사내 Gitea를 쓴다면 [부록 A](../appendix/a-self-build.md)의 주소를 넣습니다.
  3-1에서 씁니다.

> 채운 메모는 튜토리얼이 끝날 때까지 열어 두세요. `LLM_API_KEY` 는 0-2에서 OpenBao에
> 넣고 나면 메모에서 지워도 됩니다.
